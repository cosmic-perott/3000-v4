## Project
a 3d crowd scanning machine that is used in big crowd areas such as theme parks or festivals.
the machine can detect the amount of crowd density/area and can display it on a 2d screen made with processing. this is in order to alert authorities of large crowded spaces and prevent any accidents caused by a big crowd.
the machine can also track individuals and their path of movement--aiming to predict the person's next location. this is in order to find children who are lost in crowded areas
